# Ved Joshi: personal site

A personal website you explore as a low-poly 3D wolf on a small island, with a plain page view as a fallback. Plain HTML, CSS and JavaScript with three.js; no build step.

- **Live:** https://joshi-ved.github.io/ (once GitHub Pages is enabled)
- **Update the content:** edit `content.js` and add pictures to `photos/`. Full guide in [UPDATING.md](UPDATING.md).
- **Run locally:** open `index.html` in a browser, or run `npx serve` in this folder.
